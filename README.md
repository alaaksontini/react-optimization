# Optimisation des performances React

Projet d'exercices interactifs pour apprendre à optimiser les re-rendus en React.

## Exercices

Chaque exercice contient un composant **volontairement mal écrit**. Un badge rouge affiche le nombre de re-rendus de chaque composant en temps réel. Lisez le commentaire `TODO` dans le fichier source et appliquez la bonne optimisation.

| # | Concept | Fichier à modifier |
|---|---|---|
| 1 | `React.memo` | `src/exercises/01-memo/ChildProfile.tsx` |
| 2 | `useMemo` | `src/exercises/02-useMemo/ExpensiveList.tsx` |
| 3 | `useCallback` | `src/exercises/03-useCallback/SearchParent.tsx` |
| 4 | `React.lazy` | `src/exercises/04-lazy/AppShell.tsx` |

## Installation

```bash
npm install
npm run dev
```

Ouvrez [http://localhost:5173](http://localhost:5173) dans votre navigateur.
